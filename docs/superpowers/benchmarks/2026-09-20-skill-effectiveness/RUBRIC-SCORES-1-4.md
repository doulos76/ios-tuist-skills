# Rubric Scores — Comparisons 1–4

Independent grading pass against PRD §5.1 (structural rubric, 0–2 per
item, N/A-full-credit where an item doesn't apply) and §5.2
(real-artifact pass/fail). Scored from the raw report files only; no
other comparison's files or the aggregate summary were read while
scoring.

**Contamination caveat (applies to all four baselines below):** every
`*-baseline.md` file is explicitly labeled CONTAMINATED — generated by
a session/subagents with prior exposure to this repo's skill content,
not a genuinely naive baseline. Scores below reflect what is actually
written in each report, not a claim that these numbers represent what
an unexposed baseline session would produce. Per the task instructions
this caveat is noted but does not change how the rubric was applied.

## 3. `version-mismatch` (ios-tuist-feature, Scenario C — report mismatch, don't reconcile)

`EXPECTATIONS.md`) is to test whether a Tuist version mismatch between
the project's `.tool-versions` pin (4.62.0) and the machine's other
installed/active versions (4.206.0 installed, 4.194.1 global default)
gets explicitly detected and reported, not silently glossed over.

exercised or disclosed — a reader of the baseline response alone would
never learn a mismatch existed. The with-skill response detected,
enforced against, and explicitly surfaced the exact risk this fixture
tests for. Real-artifact pass/fail is identical between conditions,
which itself is a finding worth noting: BUILD/TEST passing is not
sufficient evidence of correct version-safety judgment, exactly the
gap PRD §5.2's closing paragraph warns about.

wrong, even though the outcome itself failed. The with-skill run's
real-artifact result is strictly better (BUILD/TEST PASS vs. FAIL,

per item 1), but its own verification during the run was incomplete

item 5 that the baseline, despite failing, did not lose. Net: with-skill

real-artifact axis (PASS vs. FAIL), but this comparison is the closest
of the four on rubric score and is worth flagging as the one case
where "with-skill" is not a clean sweep across every dimension.

## Known limitations (per PRD §8, restated for this scoring pass)

- All four `*-baseline.md` files are explicitly labeled CONTAMINATED —
  generated by a session/subagents with prior exposure to this repo's
  skill content. Scores above are the rubric applied to what is
  actually written in each report, not a claim that they represent a
  genuinely naive baseline session's behavior. A true baseline rerun
  (fresh `claude` session, no `--plugin-dir`, per `EXECUTION-GUIDE.md`)
  is still required before these baseline numbers can be used as the
  PRD's authoritative comparison.
- N=1 per condition per comparison, single grading pass, one grader —
  the same limitation the PRD itself states for the whole benchmark
  (§3, §6.3).
- This file scores only comparisons 1–4 of the PRD's 12 total
  comparisons.

# Independent Rubric Scoring — Comparisons 5–8

Scored per `docs/superpowers/specs/2026-09-20-skill-effectiveness-benchmark-prd.md`
§5.1 (structural rubric, 0–2 per item, N/A = full credit) and §5.2
(real-artifact pass/fail). Each comparison scored independently, fresh,
from the raw report files only — no cross-comparison or aggregate-summary
context was consulted.

**Contamination caveat (applies to all four `*-baseline.md` files):**
every baseline report in this batch is explicitly labeled
CONTAMINATED — generated by a session/subagent with structural exposure
to this repository's own skill content, not a genuinely naive
zero-plugin session. Per instructions, these are scored on what the
report actually contains (the rubric measures response behavior), but
the resulting score is **not evidence of what a truly naive baseline
would produce** — treat these baseline scores as an upper bound on
baseline performance, not a representative sample.

## Comparison 1: `extract-candidate` (networking scenario)

`extract-candidate-networking-with-skill.md`

(read directly, not just from the reports) contains only
`SettingsRow(title: "Notifications", isOn: true)` — it never references
`APIEndpoint`, `APIRequestBuilder`, or anything from `Networking.swift`.
